Search Tips

Change Date Range: The Search Range Default is set to return results for the last two years. If you need to search for documents that fall into a more specific range, e.g. last week, use the Date Range Drop Down to pick the range that you would like to search.

Set a Custom Time/Date Range: If you want to narrow results to a specific date range, use the drop down and enter dates in the Custom Date Range Calendar. If you want to find a document within a particular date range, you could search Trees and add a date range to only get results that fit into that time period.

Use quotations (" ") to search for the exact phrase: If you search for Imperial Street, you will get results that have all those words, but not necessarily in the order you search. By adding quotations and searching "Imperial Street" you will get only results that include all those words in that order.

Find one result or the other with OR: If you're looking for results that are about one topic or another, but nothing else, use the OR modifier to get more accurate results. For example, searching Balboa Coronado will return results relating to either term, but searching "Balboa OR Coronado" provides you with separate links about each.
